================================================================================
ПОЛНОЕ ТЕХНИЧЕСКОЕ РУКОВОДСТВО: ОБУЧЕНИЕ ХОДЬБЕ И РАЗВОРОТАМ РОБОТА UNITREE G1 В UNITY
================================================================================

Данный документ представляет собой пошаговое руководство для воспроизведения стабильной, 
физически корректной ходьбы и разворотов на 180 градусов для двуногого 29-DOF робота 
Unitree G1 с использованием библиотеки Unity ML-Agents и алгоритма PPO (Proximal Policy Optimization).

Это руководство составлено специально для повторения эксперимента «с нуля» 
или переноса обученной модели в новые сцены, включая демонстрационный сценарий доставки коробки.
Все скрипты адаптированы под архитектуру независимых параллельных сред (без глобальных синглтонов).

--------------------------------------------------------------------------------
1. АРХИТЕКТУРА И ПОДГОТОВКА СЦЕНЫ В UNITY
--------------------------------------------------------------------------------

Для стабильного обучения двуногого робота критически важна физическая стабильность симулятора 
и правильная настройка сочленений (Articulation Bodies).

А. Настройки физики робота (Articulation Bodies):
   - Все подвижные суставы робота должны быть импортированы как ArticulationBody.
   - Для всех суставов необходимо настроить PD-контроллеры в инспекторе:
     * Жесткость привода (Stiffness / Kp) = 200
     * Демпфирование (Damping / Kd) = 20
   - В корневом префабе или скрипте инициализации для каждого звена (ArticulationBody) 
     должно быть повышено количество итераций расчета физики (это предотвращает «взрывы» и подергивания):
     * solverIterations = 30
     * solverVelocityIterations = 12
   - Стопы робота (особенно звенья 'ankle_roll', 'foot' или 'toe') склонны проваливаться сквозь пол 
     при контакте на высокой скорости. Для борьбы с этим переключите режим обнаружения столкновений:
     * collisionDetectionMode = CollisionDetectionMode.ContinuousSpeculative

Б. Настройка датчиков стоп (Foot Sensors):
   - Создайте C# скрипт `FootSensor.cs` (код ниже).
   - Прикрепите этот скрипт к левой стопе (звено `left_ankle_roll_link` или аналогичное) 
     и к правой стопе (`right_ankle_roll_link`).
   - Навесьте на эти же звенья физические коллайдеры (обычно BoxCollider на подошве стопы), 
     настроенные как обычные материальные коллайдеры (НЕ триггеры).
   - Убедитесь, что слои физики настроены так, чтобы стопы сталкивались с поверхностью земли.

В. Настройка компонента G1Agent на роботе:
   - Прикрепите скрипт `G1Agent.cs` (код ниже) к родительскому объекту робота.
   - Создайте на сцене объект-цель (например, простую сферу) и перетащите ее в поле "Target" скрипта G1Agent.
   - Поместите трансформ головы робота (обычно звено `head_link` or `neck_link`) в поле "Head Transform". 
     Если оставить поле пустым, скрипт попытается найти его автоматически по имени.
   - Перетащите скрипты FootSensor с левой и правой стопы в соответствующие поля "Left Foot" и "Right Foot" в инспекторе.

Г. Параметры MLAgents компонентов:
   - Компонент Behavior Parameters:
     * Behavior Name: G1Walking
     * Vector Observation -> Space Size: 74 (строго!)
     * Actions -> Continuous Actions: 29 (по числу суставов робота)
     * Actions -> Discrete Actions: 0
     * Behavior Type: Default (во время обучения) или Inference Only (при проверке модели)
   - Компонент Decision Requester:
     * Decision Period: 5 (сеть принимает решения каждые 5 физических шагов симуляции).

Д. Настройка сценария и дублирование сред (Demo Mode):
   - Для создания финального сценария доставки оставьте на сцене **одного робота** (всех остальных роботов для обучения удалите).
   - Создайте пустой родительский GameObject (например, `Environment_1`), поместите туда робота G1, вейпоинты и летающий куб.
   - Накиньте на `Environment_1` (или пустой дочерний объект) скрипт `DeliveryManager.cs` (код ниже).
   - Заполните в инспекторе `DeliveryManager` локальные ссылки на этого робота G1, вейпоинты путей «Туда»/«Обратно» и летающие кубы.
   - В инспекторе `G1Agent` перетащите этот локальный `DeliveryManager` в поле **`Delivery Manager`**, а также поставьте галочку **`Demo Mode`** = `True`.
   - **ДУБЛИРОВАНИЕ:** Теперь ты можешь полностью сдублировать объект `Environment_1` (получив `Environment_2`, `Environment_3` и т.д.). Unity автоматически обновит все перекрестные ссылки внутри каждого сдублированного контейнера. Среды будут работать абсолютно независимо друг от друга в параллельных коридорах!

=== ФАЙЛ 1: FootSensor.cs ===
```csharp
using UnityEngine;

public class FootSensor : MonoBehaviour
{
    public bool isGrounded { get; private set; }

    private void OnCollisionStay(Collision collision)
    {
        isGrounded = true;
    }

    private void OnCollisionExit(Collision collision)
    {
        isGrounded = false;
    }

    private void FixedUpdate()
    {
        if (Physics.OverlapSphere(transform.position, 0.05f).Length <= 1)
        {
            isGrounded = false;
        }
    }
}
```

=== ФАЙЛ 2: DeliveryManager.cs ===
```csharp
using UnityEngine;
using System.Collections.Generic;

public class DeliveryManager : MonoBehaviour
{
    public enum DeliveryState
    {
        WalkingToCube,
        CarryingBack,
        Finished
    }

    [Header("State")]
    public DeliveryState currentState = DeliveryState.WalkingToCube;

    [Header("Agent Settings")]
    public G1Agent agent;

    [Header("Cube Objects")]
    public GameObject standaloneCube;
    public GameObject visualCubeInHands;
    public GameObject deliveredCubeAtHome;

    [Header("Path To Cube (Путь туда)")]
    public List<Transform> pathToCube = new List<Transform>();

    [Header("Path Back Home (Путь обратно)")]
    public List<Transform> pathBackHome = new List<Transform>();

    [Header("Visual Path Settings")]
    public LineRenderer lineRenderer;
    public Color pathToCubeColor = Color.cyan;
    public Color pathBackHomeColor = Color.yellow;

    private int currentPathIndex = 0;

    private void Start()
    {
        if (agent == null)
        {
            agent = FindFirstObjectByType<G1Agent>();
        }

        if (agent != null && agent.deliveryManager == null)
        {
            agent.deliveryManager = this;
        }

        ResetDeliveryScenario();
    }

    public void ResetDeliveryScenario()
    {
        currentState = DeliveryState.WalkingToCube;
        currentPathIndex = 0;

        if (standaloneCube != null) standaloneCube.SetActive(true);
        if (visualCubeInHands != null) visualCubeInHands.SetActive(false);
        if (deliveredCubeAtHome != null) deliveredCubeAtHome.SetActive(false);

        if (agent != null)
        {
            agent.demoMode = true;
            agent.lockArmsForDelivery = false;

            if (pathToCube.Count > 0)
            {
                agent.target = pathToCube[0];
                Debug.Log($"[{gameObject.name}] Сценарий запущен для {agent.name}. Цель: {pathToCube[0].name}");
            }
        }

        UpdateLineRenderer();
    }

    public void OnWaypointReached(G1Agent reachedAgent)
    {
        if (currentState == DeliveryState.WalkingToCube)
        {
            Debug.Log($"[{gameObject.name}] {reachedAgent.name} достиг точки 'Туда': {pathToCube[currentPathIndex].name}");
            
            if (currentPathIndex >= pathToCube.Count - 1)
            {
                currentState = DeliveryState.CarryingBack;
                currentPathIndex = 0;

                if (standaloneCube != null) standaloneCube.SetActive(false);
                if (visualCubeInHands != null) visualCubeInHands.SetActive(true);

                reachedAgent.lockArmsForDelivery = true; 
                reachedAgent.AddReward(5.0f);

                if (pathBackHome.Count > 0)
                {
                    reachedAgent.target = pathBackHome[0];
                    Debug.Log($"[{gameObject.name}] Куб взят! Возвращаемся домой. Новая цель: {pathBackHome[0].name}");
                }
            }
            else
            {
                currentPathIndex++;
                reachedAgent.target = pathToCube[currentPathIndex];
                reachedAgent.AddReward(2.0f);
            }
        }
        else if (currentState == DeliveryState.CarryingBack)
        {
            Debug.Log($"[{gameObject.name}] {reachedAgent.name} достиг точки 'Обратно': {pathBackHome[currentPathIndex].name}");

            if (currentPathIndex >= pathBackHome.Count - 1)
            {
                currentState = DeliveryState.Finished;

                if (visualCubeInHands != null) visualCubeInHands.SetActive(false);
                if (deliveredCubeAtHome != null) deliveredCubeAtHome.SetActive(true);

                reachedAgent.lockArmsForDelivery = false; 
                reachedAgent.AddReward(15.0f); 
                
                Debug.Log($"[{gameObject.name}] Успешная доставка куба домой!");
                Invoke(nameof(ResetDeliveryScenarioAndAgent), 3f);
            }
            else
            {
                currentPathIndex++;
                reachedAgent.target = pathBackHome[currentPathIndex];
                reachedAgent.AddReward(2.0f);
            }
        }

        UpdateLineRenderer();
    }

    private void ResetDeliveryScenarioAndAgent()
    {
        ResetDeliveryScenario();
        if (agent != null)
        {
            agent.EndEpisode(); 
        }
    }

    private void UpdateLineRenderer()
    {
        if (lineRenderer == null) return;

        List<Transform> activePath = (currentState == DeliveryState.WalkingToCube) ? pathToCube : pathBackHome;
        lineRenderer.startColor = (currentState == DeliveryState.WalkingToCube) ? pathToCubeColor : pathBackHomeColor;
        lineRenderer.endColor = lineRenderer.startColor;

        if (activePath.Count > 0)
        {
            lineRenderer.positionCount = activePath.Count;
            for (int i = 0; i < activePath.Count; i++)
            {
                if (activePath[i] != null)
                {
                    lineRenderer.SetPosition(i, activePath[i].position);
                }
            }
        }
    }

    private void OnDrawGizmos()
    {
        if (pathToCube.Count > 0)
        {
            Gizmos.color = Color.cyan;
            for (int i = 0; i < pathToCube.Count; i++)
            {
                if (pathToCube[i] != null)
                {
                    Gizmos.DrawWireSphere(pathToCube[i].position, 0.4f);
                    if (i < pathToCube.Count - 1 && pathToCube[i+1] != null)
                        Gizmos.DrawLine(pathToCube[i].position, pathToCube[i+1].position);
                }
            }
        }

        if (pathBackHome.Count > 0)
        {
            Gizmos.color = Color.yellow;
            for (int i = 0; i < pathBackHome.Count; i++)
            {
                if (pathBackHome[i] != null)
                {
                    Gizmos.DrawWireSphere(pathBackHome[i].position, 0.4f);
                    if (i < pathBackHome.Count - 1 && pathBackHome[i+1] != null)
                        Gizmos.DrawLine(pathBackHome[i].position, pathBackHome[i+1].position);
                }
            }
        }
    }
}
```

=== ФАЙЛ 3: G1Agent.cs ===
```csharp
using UnityEngine;
using Unity.MLAgents;
using Unity.MLAgents.Sensors;
using Unity.MLAgents.Actuators;
using System.Collections.Generic;

public class G1Agent : Agent
{
    [Header("Robot Parts")]
    public List<ArticulationBody> joints = new List<ArticulationBody>();
    public Transform target; 

    private ArticulationBody rootBody; 
    
    [Header("Posture Control")]
    public Transform headTransform;
    
    [Header("Foot Ground Sensors")]
    public FootSensor leftFoot;
    public FootSensor rightFoot;

    [Header("Demo / Path Following Settings")]
    public bool demoMode = false;
    public bool lockArmsForDelivery = false;
    public DeliveryManager deliveryManager;

    private int episodeSteps = 0;
    private int obsSize; 

    private Vector3 initialLocalPosition;
    private Quaternion initialLocalRotation;
    private Vector3 initialPelvisPosition;
    private Quaternion initialPelvisRotation;
    
    private List<float> initialJointTargetsDegrees = new List<float>(); 
    private List<float> initialJointPositions = new List<float>();       
    private float fallThresholdHeight; 

    public override void Initialize()
    {
        joints.Clear();
        initialJointTargetsDegrees.Clear();
        initialJointPositions.Clear();

        DecisionRequester dr = GetComponent<DecisionRequester>();
        if (dr == null)
        {
            dr = gameObject.AddComponent<DecisionRequester>();
            dr.DecisionPeriod = 5;
        }

        initialLocalPosition = transform.localPosition;
        initialLocalRotation = transform.localRotation;

        ArticulationBody[] allBodies = GetComponentsInChildren<ArticulationBody>();
        foreach (var body in allBodies)
        {
            if (body.isRoot)
            {
                rootBody = body;
                break;
            }
        }

        if (rootBody == null && allBodies.Length > 0)
        {
            rootBody = allBodies[0];
        }

        if (rootBody != null)
        {
            initialPelvisPosition = rootBody.transform.position;
            initialPelvisRotation = rootBody.transform.rotation;
            fallThresholdHeight = initialPelvisPosition.y * 0.6f;
        }

        if (headTransform == null)
        {
            Transform[] allTransforms = GetComponentsInChildren<Transform>();
            foreach (var t in allTransforms)
            {
                string lowerName = t.name.ToLower();
                if (lowerName.Contains("head") || lowerName.Contains("neck"))
                {
                    headTransform = t;
                    break;
                }
            }
        }

        foreach (var body in allBodies)
        {
            body.solverIterations = 30;
            body.solverVelocityIterations = 12;

            string lowerName = body.name.ToLower();
            if (lowerName.Contains("ankle_roll") || lowerName.Contains("foot") || lowerName.Contains("toe"))
            {
                body.collisionDetectionMode = CollisionDetectionMode.ContinuousSpeculative;
            }

            if (body == rootBody || body.isRoot) continue;
            
            if (body.jointType != ArticulationJointType.FixedJoint)
            {
                joints.Add(body);
                
                float defaultTarget = body.xDrive.target;
                
                if (lowerName.Contains("elbow"))
                    defaultTarget = 15f; 
                else if (lowerName.Contains("shoulder_pitch"))
                    defaultTarget = 0f; 
                else if (lowerName.Contains("shoulder_roll"))
                    defaultTarget = 0f; 
                else if (lowerName.Contains("shoulder_yaw"))
                    defaultTarget = 0f; 
                else if (lowerName.Contains("knee"))
                    defaultTarget = 25f; 
                
                initialJointTargetsDegrees.Add(defaultTarget);
                initialJointPositions.Add(defaultTarget * Mathf.Deg2Rad);
                
                var drive = body.xDrive;
                drive.stiffness = 200f; 
                drive.damping = 20f;    
                body.xDrive = drive;
            }
        }

        obsSize = 16 + joints.Count * 2;
    }

    public override void OnEpisodeBegin()
    {
        episodeSteps = 0;

        float spawnYaw = 0f;
        if (!demoMode)
        {
            spawnYaw = Random.value > 0.5f ? Random.Range(90f, 180f) : Random.Range(-180f, -90f);
        }

        transform.localPosition = initialLocalPosition;
        transform.localRotation = initialLocalRotation * Quaternion.Euler(0f, spawnYaw, 0f);
        
        if (rootBody != null)
        {
            rootBody.linearVelocity = Vector3.zero;
            rootBody.angularVelocity = Vector3.zero;

            Vector3 safeSpawnPos = initialPelvisPosition + new Vector3(0f, 0.03f, 0f);
            Quaternion spawnRotation = initialPelvisRotation * Quaternion.Euler(0f, spawnYaw, 0f);
            rootBody.TeleportRoot(safeSpawnPos, spawnRotation);
            
            rootBody.linearVelocity = Vector3.zero;
            rootBody.angularVelocity = Vector3.zero;
        }

        for (int i = 0; i < joints.Count; i++)
        {
            var joint = joints[i];
            if (joint.dofCount > 0 && i < initialJointPositions.Count)
            {
                joint.jointPosition = new ArticulationReducedSpace(initialJointPositions[i]);
            }
            joint.jointVelocity = new ArticulationReducedSpace(0f);
            
            var drive = joint.xDrive;
            drive.target = initialJointTargetsDegrees[i];
            drive.targetVelocity = 0f;
            joint.xDrive = drive;
        }
    }

    public override void CollectObservations(VectorSensor sensor)
    {
        if (rootBody == null)
        {
            for (int i = 0; i < obsSize; i++) sensor.AddObservation(0f);
            return;
        }

        if (float.IsNaN(rootBody.transform.position.y) || float.IsNaN(rootBody.transform.rotation.x))
        {
            for (int i = 0; i < obsSize; i++) sensor.AddObservation(0f);
            return;
        }

        sensor.AddObservation(rootBody.transform.position.y);
        sensor.AddObservation(rootBody.transform.rotation);
        sensor.AddObservation(rootBody.linearVelocity);
        sensor.AddObservation(rootBody.angularVelocity);

        Vector3 worldToTarget = (target != null) ? (target.position - rootBody.transform.position) : Vector3.zero;
        Vector3 localToTarget = rootBody.transform.InverseTransformDirection(worldToTarget);
        sensor.AddObservation(localToTarget);

        foreach (var joint in joints)
        {
            if (joint.dofCount > 0)
            {
                sensor.AddObservation(joint.jointPosition[0]);
                sensor.AddObservation(joint.jointVelocity[0]);
            }
        }

        sensor.AddObservation(leftFoot != null && leftFoot.isGrounded ? 1f : 0f);
        sensor.AddObservation(rightFoot != null && rightFoot.isGrounded ? 1f : 0f);
    }

    public override void OnActionReceived(ActionBuffers actions)
    {
        episodeSteps++;

        var continuousActions = actions.ContinuousActions;
        int actionIndex = 0;

        foreach (var joint in joints)
        {
            if (actionIndex < continuousActions.Length && joint.dofCount > 0)
            {
                var drive = joint.xDrive;
                float actionVal = Mathf.Clamp(continuousActions[actionIndex], -1f, 1f);
                
                float defaultAngle = initialJointTargetsDegrees[actionIndex];
                float maxDeviation = 65f;
                
                float targetAngle = defaultAngle + actionVal * maxDeviation;

                if (lockArmsForDelivery)
                {
                    string lowerName = joint.name.ToLower();
                    if (lowerName.Contains("elbow") || lowerName.Contains("shoulder"))
                    {
                        if (lowerName.Contains("elbow"))
                            targetAngle = 75f; 
                        else if (lowerName.Contains("shoulder_pitch"))
                            targetAngle = 35f; 
                        else if (lowerName.Contains("shoulder_roll"))
                            targetAngle = 15f; 
                        else if (lowerName.Contains("shoulder_yaw"))
                            targetAngle = 0f;
                    }
                }

                targetAngle = Mathf.Clamp(targetAngle, drive.lowerLimit, drive.upperLimit);
                drive.target = targetAngle;
                joint.xDrive = drive;
                actionIndex++;
            }
        }

        if (rootBody == null) return;

        float currentY = rootBody.transform.position.y;
        float uprightBonus = Vector3.Dot(rootBody.transform.up, Vector3.up);

        if (float.IsNaN(currentY) || float.IsNaN(uprightBonus))
        {
            SetReward(-2.0f);
            EndEpisode();
            return;
        }

        Vector3 dirToTarget = (target != null) ? (target.position - rootBody.transform.position).normalized : rootBody.transform.forward;
        float facingDot = Vector3.Dot(rootBody.transform.forward, dirToTarget);
        float postureMultiplier = 1.0f;

        if (episodeSteps > 3)
        {
            if (currentY < fallThresholdHeight)
            {
                SetReward(-2.0f);
                EndEpisode();
                return;
            }

            if (uprightBonus < 0.5f) 
            {
                SetReward(-1.0f);
                EndEpisode();
                return;
            }
            AddReward(uprightBonus * 0.015f); 

            if (headTransform != null)
            {
                Vector3 pelvisPos = rootBody.transform.position;
                Vector3 headPos = headTransform.position;
                Vector3 pelvisToHead = headPos - pelvisPos;
                
                Vector3 pelvisToHeadFlat = new Vector3(pelvisToHead.x, 0, pelvisToHead.z);
                Vector3 dirToTargetFlat = new Vector3(dirToTarget.x, 0, dirToTarget.z).normalized;
                
                float globalLeanForward = Vector3.Dot(pelvisToHeadFlat, dirToTargetFlat);
                
                if (globalLeanForward < -0.02f) 
                {
                    postureMultiplier = 0.1f; 
                    AddReward(-0.02f); 
                }
                else if (globalLeanForward >= 0.05f && globalLeanForward <= 0.2f)
                {
                    AddReward(0.004f); 
                }
            }

            if (facingDot < 0.5f) 
            {
                AddReward(-0.02f); 
            }
        }

        if (target != null)
        {
            float speedTowardTarget = Vector3.Dot(rootBody.linearVelocity, dirToTarget);
            float directionMultiplier = Mathf.Clamp01(facingDot);

            if (speedTowardTarget > 0)
            {
                AddReward(speedTowardTarget * 0.2f * directionMultiplier * postureMultiplier);
            }
            else
            {
                AddReward(speedTowardTarget * 0.1f);
            }

            float currentDistance = Vector3.Distance(rootBody.transform.position, target.position);
            if (currentDistance < 1.0f)
            {
                if (demoMode && deliveryManager != null)
                {
                    deliveryManager.OnWaypointReached(this);
                }
                else if (demoMode && CheckpointManager.Instance != null)
                {
                    CheckpointManager.Instance.OnCheckpointReached(this);
                }
                else
                {
                    Debug.Log($"[G1Agent] Эпизод завершен (Успех)! Шагов: {episodeSteps}");
                    AddReward(10.0f); 
                    EndEpisode();
                    return;
                }
            }
        }

        float actionPenalty = 0f;
        for (int i = 0; i < continuousActions.Length; i++)
        {
            actionPenalty += Mathf.Abs(continuousActions[i]);
        }
        AddReward(- (actionPenalty / continuousActions.Length) * 0.025f);

        float yawSpeed = Mathf.Abs(rootBody.angularVelocity.y);
        AddReward(-yawSpeed * 0.003f);
    }
}
```
