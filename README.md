# Автономная навигация гуманоидного робота (Unity ML-Agents)

Этот проект демонстрирует использование алгоритмов обучения с подкреплением (Reinforcement Learning), в частности PPO (Proximal Policy Optimization), для обучения гуманоидного робота G1 физически корректной ходьбе и навигации в сложном лабиринте.

## Описание проекта
Робот обучается с нуля (tabula rasa), имея в распоряжении только свои физические суставы (управляемые PD-контроллерами) и систему наград. Задача робота — удерживать баланс, двигаться вперед, огибать препятствия и достигать конечной цели, а затем возвращаться обратно.

### Ключевые особенности:
- **Физика**: Используется `ArticulationBody` для точной симуляции суставов и физических ограничений робота.
- **Обучение**: Unity ML-Agents (PPO).
- **Curriculum Learning**: Постепенное усложнение задачи (например, обучение развороту через спавн на финише).
- **Сенсоры**: Датчики жестких коллизий со стенами (Wall Collision Sensor), датчики касания стоп (Ground Sensors) и проприоцепция (углы и скорости суставов).

## Структура
- `Assets/Scripts/G1Agent.cs` — Главный скрипт нейросети. Управляет суставами, собирает наблюдения и выдает награды.
- `Assets/Scripts/DeliveryManager.cs` — Стейт-машина (менеджер логики), которая переключает цели робота (туда и обратно).
- `Assets/Scripts/WallCollisionSensor.cs` — Датчик жестких столкновений со стенами (для пенальти).
- `g1_walking_config.yaml` — Конфигурация гиперпараметров для нейросети (PPO).

## История обучения (Runs)
Вся эволюция нейросети сохранена в истории ранов. 

- **Run 1 — Run 10**: Базовое обучение ходьбе по прямой и разворотам на пустой плоскости. Робот учился держать баланс, не падать и плавно переставлять ноги (исторический срез доступен в ветке `basic-walking`). В конце 10-го рана мы получили идеальную уверенную походку.
- **Run 11 — Run 14**: **Старт лабиринта**. Обучение навигации. Робот был помещен в сложный лабиринт с препятствиями (добавлены `WallCollisionSensor`). Нейросеть наследовала веса из 10-го рана и начала адаптировать свою походку под узкие коридоры. К 14-му рану робот научился идеально проходить лабиринт в одну сторону.
- **Run 15 — Run 16+**: Обучение развороту и обратному пути (Delivery).

## Запуск обученной модели (Inference)
1. Откройте тестовую сцену в Unity.
2. Выберите объект робота (с компонентом `G1Agent`).
3. Убедитесь, что в поле `Model` в компоненте `Behavior Parameters` вставлен `.onnx` файл обученной нейросети.
4. Нажмите **Play** в Unity Editor. Робот пойдет сам.

## Запуск обучения
```powershell
mlagents-learn g1_walking_config.yaml --run-id=G1_Run_Name
```
